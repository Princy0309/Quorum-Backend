# Frontend Integration Guide: OTP & Password Resets

This document is specifically for **Princy (Frontend/Mobile Developer)**. It explains the exact flow, screens, and API calls you need to build in the Flutter app to handle Email Verification and Password Resets.

---

## 📱 Flow 1: Email Verification
When a new user registers, their account is marked as `isEmailVerified: false`. You need to guide them through verifying their email before they can use the app fully.

### **Screen 1: The Verification Prompt**
After a successful registration or login (if `isEmailVerified` is false):
1.  Show a screen saying: *"Please verify your email."*
2.  Provide a button: **"Send Verification Code"**
3.  **Action:** When they tap the button, make the following API call:
    *   **Endpoint:** `POST /api/otp/send-verification`
    *   **Headers:** `Authorization: Bearer <accessToken>`
    *   **Body:** *(None)*
4.  If successful (`200 OK`), navigate the user to Screen 2.

### **Screen 2: Enter OTP**
1.  Show a screen with a 6-digit input field.
2.  **Action:** When they type the 6 digits and tap "Submit", make this API call:
    *   **Endpoint:** `POST /api/otp/verify-email`
    *   **Headers:** `Authorization: Bearer <accessToken>`
    *   **Body:** `{"otp": "123456"}`
3.  If successful, the user is now fully verified! You can route them to the Main Home Screen.

---

## 📱 Flow 2: Forgot Password
If a user forgets their password on the Login screen, they need a way to securely reset it using their email.

### **Screen 1: Request Password Reset**
1.  On the Login screen, they tap *"Forgot Password?"*.
2.  Show a screen asking for their Email address.
3.  **Action:** When they enter their email and tap "Send Code", make this API call:
    *   **Endpoint:** `POST /api/otp/forgot-password`
    *   **Body:** `{"email": "user@example.com"}`
4.  If successful (`200 OK`), navigate the user to Screen 2. *(Note: Do NOT send an Authorization header for this).*

### **Screen 2: Reset Password (The Final Step)**
1.  Show a screen with three inputs:
    *   The 6-digit OTP code (sent to their email).
    *   New Password
    *   Confirm New Password
2.  **Action:** When they fill it out and tap "Reset Password", make this API call:
    *   **Endpoint:** `POST /api/otp/reset-password`
    *   **Body:** 
        ```json
        {
          "email": "user@example.com",
          "otp": "123456",
          "newPassword": "NewSecurePassword123!"
        }
        ```
3.  If successful (`200 OK`), show a success popup and navigate them back to the original Login Screen so they can log in with their brand new password.

---

## ⚠️ Important Rules for the Frontend:
1.  **OTP Expiration:** The OTPs generated by the backend expire automatically after **5 minutes**. You might want to show a 5-minute countdown timer on the screen in Flutter so the user knows they need to hurry.
2.  **Rate Limiting:** If the user enters the wrong OTP 5 times, the backend will block them for 15 minutes. Ensure your app elegantly handles the `429 Too Many Requests` error and shows a nice snackbar message to the user!
